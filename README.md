# Hệ Thống Quản Lý Nhà Hàng (Restaurant Management System)

## 1. Thông tin môn học
- **Học phần:** Phân tích và thiết kế yêu cầu (Mã môn: 502050)
- **Nhóm thực hiện:** Nhóm 03

## 2. Đề xuất công nghệ sử dụng
- **Ngôn ngữ lập trình:** Java (JDK 17+)
- **Giao diện người dùng (UI):** Java Swing hoặc JavaFX
- **Hệ quản trị CSDL:** MySQL
- **Kết nối CSDL:** JDBC
- **Quản lý phiên bản:** Git & GitHub

## 3. Cấu trúc thư mục dự án
- `docs/`: Chứa tài liệu phân tích (yêu cầu, UML, CSDL, báo cáo, kịch bản demo).
- `java-app/`: Chứa mã nguồn chương trình Java và script CSDL.
- `prototype/`: Các bản thiết kế giao diện tĩnh.
- `slides/`: File trình chiếu báo cáo cuối kỳ.
- `screenshots/`: Hình ảnh minh họa.
